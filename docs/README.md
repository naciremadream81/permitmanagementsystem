## ❓ FAQ

### General Questions

**Q: What is the Permit Management System?**
A: A comprehensive, multi-platform system for managing construction permits, county regulations, and compliance tracking.

**Q: What platforms are supported?**
A: Web (HTML/JS), Android, iOS, and Desktop applications.

**Q: What technologies are used?**
A: Kotlin Multiplatform, Ktor, PostgreSQL, Compose Multiplatform, and Docker.

### Development Questions

**Q: How do I set up the development environment?**
A: Follow the [Development Guide](development/README.md) for detailed setup instructions.

**Q: What are the coding standards?**
A: See the [Development Guide](development/README.md#coding-standards) for style guidelines.

**Q: How do I run tests?**
A: Use `./gradlew test` or see the [Testing Guide](testing/README.md) for more options.

### Deployment Questions

**Q: How do I deploy to production?**
A: Follow the [Deployment Guide](deployment/README.md) for production deployment.

**Q: What are the system requirements?**
A: Java 21+, PostgreSQL 13+, Docker (optional), Nginx (production).

**Q: How do I configure monitoring?**
A: See the [Monitoring Guide](monitoring/README.md) for monitoring setup.

### API Questions

**Q: How do I authenticate with the API?**
A: Use JWT tokens. See the [API Documentation](api/README.md#authentication) for details.

**Q: What is the API base URL?**
A: `http://localhost:8080/api/v1` for development, your domain for production.

**Q: How do I handle errors?**
A: See the [API Documentation](api/README.md#error-handling) for error response formats.
